# SnapKart - Point of Sale (POS) Operating & Checkout Workflow

## Overview
This document defines the operational architecture, policies, and technical guidelines for point of sale (pos) operating & checkout workflow within SnapKart.

## Core Principles
- Operational reliability and high throughput
- Strict GST tax compliance (5% added to subtotal)
- Real-time stock sync with MySQL database
- Professional customer and administrator experience
