# SnapKart - Invoice Archiving & Transaction Data Retention Policy

## Overview
This document defines the operational architecture, policies, and technical guidelines for invoice archiving & transaction data retention policy within SnapKart.

## Core Principles
- Operational reliability and high throughput
- Strict GST tax compliance (5% added to subtotal)
- Real-time stock sync with MySQL database
